3.3 整数的混合运算

1. 是什么？2. 有什么作用？3. 怎么算 / 怎么做？4. 快速自测5. 考试常考6. 一句话总结7. 答案与解析

1. 是什么？

整数的混合运算，是在同一个算式中综合进行整数的加、减、乘、除、乘方和括号运算。

整数的混合运算顺序与已经学过的混合运算顺序相同。计算时既要遵守运算顺序，又要特别注意负号和括号。

  1. 有括号时，先算括号里面；
  2. 有乘方时，先算乘方；
  3. 再算乘法和除法；
  4. 最后算加法和减法；
  5. 同级运算按顺序进行。
(−5)2＋(−3)3＝25＋(−27)＝−2

2. 有什么作用？

  • 计算含括号的整数加减；
  • 计算含乘、除法的整数算式；
  • 计算同时含乘方、括号和四则运算的算式；
  • 正确处理计算过程中连续出现的正、负号。
看清算式结构 → 确定运算顺序 → 正确处理符号 → 分步计算。

3. 怎么算 / 怎么做？

① 先看算式中有没有括号

−8−(4−7)＝−8−(−3)＝−8＋3＝−5

遇到括号时，应先把括号里面的结果算出来，再继续计算。

② 有多层括号时，从里面向外计算

3＋[−15−(3−4)]＝3＋[−15−(−1)]＝3＋(−14)＝−11
从内向外，一层一层计算。

③ 有乘方时，先正确确定底数

(−5)2＋(−3)3＝25＋(−27)＝−2

(−5)2的底数是−5，而−52表示−(52)，不能混淆。

④ 乘法、除法要先于加法、减法

−12÷(−3)×4−35÷(−7)＝4×4−(−5)＝16＋5＝21

⑤ 同级的乘除运算按顺序进行

−125÷5×(−10)＝−25×(−10)＝250

不能因为后面出现乘法，就跳过前面的除法先计算。

⑥ 复杂算式先确定顺序，再动笔计算

−3×[−15＋(7−2)]＝−3×[−15＋5]＝(−3)×(−10)＝30
括号 → 乘方 → 乘除 → 加减。

6. 一句话总结

整数混合运算要先看结构，再按“括号、乘方、乘除、加减”的顺序逐步计算，同时特别注意负号、括号和同级运算的次序。
