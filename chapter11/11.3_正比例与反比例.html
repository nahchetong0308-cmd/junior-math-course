11.3 正比例与反比例

基础版｜认识概念 → 理解作用 → 掌握判断与计算 → 快速自测 → 考试应用
1. 是什么？2. 有什么作用？3. 怎么判断、怎么算？ 4. 快速自测5. 考试常考6. 一句话总结7. 答案与解析

1. 是什么？

当两个数量一起变化时，可以观察它们之间的关系。

正比例

如果两个数量对应数值的比值保持不变，那么这两个数量成正比例。

\(x\)246
\(y\)369

计算：

\[\frac{x}{y}=\frac23\]

比值始终不变，所以 \(x\) 与 \(y\) 成正比例。

反比例

如果两个数量对应数值的乘积保持不变，那么这两个数量成反比例。

\(x\)248
\(y\)1263

计算：

\[xy=24\]

乘积始终不变，所以 \(x\) 与 \(y\) 成反比例。

关键区别：正比例看“比值不变”，反比例看“乘积不变”。

2. 有什么作用？

正比例和反比例可以帮助我们判断两个变化数量之间的关系，并根据已知的一组对应数量，求另一组对应数量。

例如，在单价不变时，购买数量越多，总价也按相同的比例增加，这是正比例关系。

完成同一项工作时，如果其他条件不变，工人人数增加，所需天数减少，可以用反比例关系解决。

因此，遇到两个一起变化的数量时，重点不是只看“一个增加，另一个增加或减少”，而是判断：

\[\text{比值是否不变？}\]

或

\[\text{乘积是否不变？}\]

3. 怎么判断、怎么算？

判断正比例

看两个数量对应数值的比值是否保持不变。

如果：

\[\frac{x_1}{y_1}=\frac{x_2}{y_2}\]

那么可以按正比例关系计算。

例如：

\[\frac{3}{5}=\frac{180}{x}\]

交叉相乘：

\[3x=900\]

所以：

\[\boxed{x=300}\]

判断反比例

看两个数量对应数值的乘积是否保持不变。

如果：

\[x_1y_1=x_2y_2\]

那么可以按反比例关系计算。

例如：

\[4\times15=6x\]

所以：

\[60=6x\]
\[\boxed{x=10}\]

判断时特别注意

不能只根据“同时增加”就判断正比例，也不能只根据“一个增加、一个减少”就判断反比例。

真正的判断依据是：

\[\boxed{\text{正比例：比值不变}}\]
\[\boxed{\text{反比例：乘积不变}}\]

4. 快速自测

先独立判断，答案与解析统一放在第7项。

1. 两个数量成正比例时，它们对应数值的比值保持不变。（　　）
2. 两个数量成反比例时，它们对应数值的乘积保持不变。（　　）
3. 一个数量增加，另一个数量也增加，这两个数量就一定成正比例。（　　）
4. 若 \(x\) 与 \(y\) 成反比例，当 \(x=4,\ y=6\) 时，则当 \(x=8\) 时，\(y=3\)。（　　）

5. 考试常考

题型1：判断两个数量成正比例还是反比例

题目：

观察下表：

\(x\)248
\(y\)1263

判断 \(x\) 与 \(y\) 成正比例还是反比例。

答案：\(2\times12=4\times6=8\times3=24\)，所以 \(\boxed{x\text{ 与 }y\text{ 成反比例}}\)。

题型2：正比例应用

题目：

某汽车以相同的速度行驶，3小时行驶180 km。照这样的速度，5小时行驶多少千米？

答案：设5小时行驶 \(x\) km。
\[\frac{3}{5}=\frac{180}{x}\] \[3x=900\] \[\boxed{x=300\text{ km}}\]

题型3：反比例应用

题目：

完成同一项工作，6名工人需要12天。如果工作效率相同，改由8名工人完成，需要多少天？

答案：设需要 \(x\) 天。
\[6\times12=8x\] \[8x=72\] \[\boxed{x=9\text{天}}\]

6. 一句话总结

正比例看比值不变，反比例看乘积不变；先判断关系，再选择相应的比例方法计算。

7. 快速自测答案与解析

1. 两个数量成正比例时，它们对应数值的比值保持不变。（　　）

答案：正确
解析：正比例的判断关键就是对应数值的比值保持不变。

2. 两个数量成反比例时，它们对应数值的乘积保持不变。（　　）

答案：正确
解析：反比例的判断关键是对应数值的乘积保持不变。

3. 一个数量增加，另一个数量也增加，这两个数量就一定成正比例。（　　）

答案：错误
解析：同时增加不代表一定成正比例，还要检查对应数值的比值是否保持不变。

4. 若 \(x\) 与 \(y\) 成反比例，当 \(x=4,\ y=6\) 时，则当 \(x=8\) 时，\(y=3\)。（　　）

答案：正确
解析：\(4\times6=8\times3=24\)，乘积不变。

5. 判断两个数量是否成反比例，只要看一个增加时另一个是否减少即可。（　　）

答案：错误
解析：一增一减还不够，必须检查两个数量对应数值的乘积是否保持不变。
