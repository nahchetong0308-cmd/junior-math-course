3.5 数列

基础版｜观察已知项 → 找出一致规律 → 检查规律 → 写出后续项
1. 是什么？2. 有什么作用？3. 怎么判断 / 怎么做？4. 快速自测5. 考试常考6. 一句话总结7. 答案与解析

1. 是什么？

把一列数按照一定的次序排列起来，可以形成一个数列。

例如：

2，5，8，11，14，……

这一列数中，从第二个数开始，每一个数都比前一个数多3。

又如：

3，6，12，24，48，……

从第二个数开始，每一个数都是前一个数的2倍。

学习数列，关键不是只看某两个数之间的关系，而是找出一个能够连续解释已知各项的规律，再按照同一个规律继续写下去。

2. 有什么作用？

  • 根据相邻两项之间固定的加减关系继续写数；
  • 根据相邻两项之间固定的倍数关系继续写数；
  • 发现相邻两项之间逐步变化的关系；
  • 根据前面几项之间的关系确定下一项；
  • 识别平方、立方、乘积等数值结构；
  • 识别正负号交替或分组出现的组合规律。
观察已知项 → 找出一致规律 → 检查规律 → 写出后续项。

3. 怎么判断 / 怎么做？

① 先看相邻两项是不是固定增加或减少

4，9，14，19，24，……
相邻两项都增加5 → 29，34，39

如果每次减少同一个数，也按同样的方法判断：

30，26，22，18，……
每次减少4 → 14，10，6

② 再看相邻两项是不是按固定倍数变化

2，6，18，54，……
每一项都是前一项的3倍 → 162，486，1458

③ 如果不是固定加减，要检查“变化量”本身有没有规律

2，5，9，14，20，……
依次增加3，4，5，6 → 再增加7，8，9
→ 27，35，44

④ 检查下一项是不是由前面几项得到

1，1，2，3，5，8，……
从第三项开始，每一项都是前两项之和
→ 13，21，34

⑤ 观察每一项本身有没有特殊数值结构

1，4，9，16，25，……
＝12，22，32，42，52，……
→ 36，49，64

遇到这类数列，不能只盯着相邻两项的差，还要观察每一个数本身的结构。

⑥ 注意正负号、位置或分组是否有规律

1，−2，3，−4，5，−6，……
数值依次为1，2，3，4，5，6，……
符号按＋，−，＋，−，＋，−，……交替
→ 7，−8，9
判断数列规律的基本顺序：固定加减 → 固定倍数 → 相邻变化量 → 前几项关系 → 数值结构 → 正负号或分组结构。

找到规律以后，还要回头检查：这个规律能不能一致解释已经给出的各项？如果不能，就要重新寻找规律。

6. 一句话总结

找数列规律要从相邻项的加减、倍数、变化量、前几项关系、数值结构和正负号等方面观察，并用同一个规律检查全部已知项后再写出后续项。

7. 快速自测答案与解析

1. 数列5，8，11，14，……中，每一项都比前一项增加3。（　　）

答案：正确
解析：相邻两项的差都是3。

2. 数列2，6，18，54，……的下一项是108。（　　）

答案：错误
解析：每一项都是前一项的3倍，因此下一项是54×3＝162。

3. 数列1，4，9，16，25，……可以从平方数的结构观察规律。（　　）

答案：正确
解析：这些数依次是12，22，32，42，52，……

4. 数列1，1，2，3，5，8，……从第三项开始，每一项都是前两项之和。（　　）

答案：正确
解析：例如1＋1＝2、1＋2＝3、2＋3＝5。

5. 只要一个规律能够解释数列中的前两项，就一定可以用它确定整个数列的后续项。（　　）

答案：错误
解析：找到的规律必须能够一致解释已经给出的各项，不能只检查前两项。
